Second pass. Skills now live as a third segment on Stats; the gear is Settings again, and the test list is managed from Settings → Skills tests. Switch the role to see the parent view and the sport to preview the draft default sets. Nothing is saved.

Try this
  1. On Stats, tap the Skills segment: every player's personal best per test, with an arrow when the latest result beat or missed the one before. Swipe the table sideways.
  2. Tap Nolan (there or on the Roster): the four season tiles, guardians (coach view only) and the Skills list with trend lines. Playing time is gone from this page.
  3. Tap Juggling for the history, then Record a result. Tap an old result to edit or delete it.
  4. Tap the gear, then Skills tests. Hide, reorder, tap a test to edit it (metric locks once it has results), add a custom one, or restore hidden defaults. There is no cross-sport library: each sport's set already includes its own sprint-speed test. Try deleting Juggling: it refuses because it has history.
  5. Switch to Parent: the Skills table shrinks to Nolan, Record and the test editor disappear, and other kids' pages show no skills.
Assistant coaches can edit the test list and record results, same as the head coach. Baseball, basketball and lacrosse default sets are drafts for your review. Built-ins come back only through Restore defaults; new tests only through Add a custom test.
